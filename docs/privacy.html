Privacy policy — Manual Video Zoom

Effective date: September 15, 2026. Applies to Manual Video Zoom 1.0.0 and later.

English

Manual Video Zoom adjusts the visual size of HTML5 videos on selected websites. It runs locally in your browser. The extension sends no data to the developer or third parties and includes no analytics, advertising, tracking, remote scripts or external requests.

The extension accesses video elements and their dimensions, visibility and inline CSS on the sites listed in its manifest, and on any additional site you explicitly allow from its popup. Allowing a site is your choice, is recorded by Chrome as a site permission rather than by this extension, and can be withdrawn in chrome://extensions under Details, Site access. The extension reads the current tab's address only while you have its popup open, to name the site on the button that asks for that permission; the address is not stored or sent anywhere. It temporarily remembers original style values so that Reset can restore them. It does not access video pixels, decrypt protected media, read account details or record video titles or full page URLs. Website permissions technically allow reading and changing content within the permitted scope; the implementation uses them for video sizing.

It stores one zoom percentage per site origin (scheme and hostname, for example https://www.netflix.com) using chrome.storage.local. This association is a local preference, not a browsing-history log. It is not sent to a server or stored using Chrome's sync storage. Live tab identifiers are used only to direct controls to the active tab and are not saved. Ordinary traffic generated by the streaming websites themselves is outside this extension's control.

Reset replaces the site's saved percentage with 100%. Uninstalling the extension removes its local settings; reload open pages to remove already-injected code. No data is sold or transferred. The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Future changes to these practices will be reflected in an updated policy.

Questions, or a privacy or security report: kk@nekoreset.com, or the issue tracker for anything that is not sensitive.

日本語

Manual Video Zoomは、対象サイトのHTML5動画の表示サイズをブラウザー内で調整します。開発者や第三者へのデータ送信、解析、広告、追跡、外部コードの読み込み、外部通信は行いません。

manifestに記載されたサイトと、利用者がポップアップから明示的に許可したサイトで、動画要素の寸法・表示状態・インラインCSSを参照し、リセットできるよう変更前のスタイルを一時的に記憶します。サイトの許可は利用者の操作で行われ、本拡張ではなくChromeがサイト権限として保持します。chrome://extensions の「詳細」→「サイトへのアクセス」で取り消せます。現在のタブのURLは、許可を求めるボタンにサイト名を表示するためにポップアップを開いている間だけ参照し、保存も送信もしません。映像の画素取得、保護された動画の復号、アカウント情報の参照、作品名や完全なページURLの記録は行いません。サイト権限は技術的には対象範囲の内容を読み書きできますが、本実装では動画サイズの調整に使用します。

サイトのオリジン（スキームとホスト名）ごとに倍率を chrome.storage.local へ保存します。これは端末内の設定であり、閲覧履歴のログではありません。サーバーへ送信せず、Chromeの同期用ストレージも使用しません。現在のタブの識別子は操作の送信先として一時的に使用し、保存しません。動画サイト自身が行う通信は本拡張の管理対象外です。

リセットすると保存倍率を100%に置き換えます。拡張を削除すると設定も削除されます。開いたままのページは再読み込みしてください。データの販売や移転は行いません。Google APIから受け取った情報の利用は、Limited Use要件を含むChromeウェブストアのユーザーデータに関するポリシーに従います。取り扱いを変更する場合はポリシーを更新します。

お問い合わせ、プライバシーやセキュリティに関する報告は kk@nekoreset.com へ。機微な内容でなければ GitHubのIssue もご利用いただけます。
